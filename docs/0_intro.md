# ВСТУП

## Актуальність теми
Постпандемічний розвиток індустрії TravelTech вимагає впровадження інтелектуальних систем автоматизованого планування, здатних подолати розрив між стохастичною генерацією намірів користувача та жорсткими просторово-часовими обмеженнями логістики. Сучасні підходи часто стикаються з проблемою «логістичних галюцинацій» великих мовних моделей (LLM), які не враховують матриці транзитного часу та графіки роботи об'єктів. 

Актуальність роботи полягає в проєктуванні архітектури, що забезпечує детерміноване розв'язання NP-складних задач маршрутизації з часовими вікнами (VRPTW) шляхом ізоляції непередбачуваності LLM у фонових чергах і використання векторного пошуку для семантичної фільтрації кандидатів.

## Об'єкт дослідження
Процес автоматизованого планування просторово-розподілених маршрутів подорожей та управління інфраструктурними ресурсами на основі гібридних інтелектуальних моделей.

## Предмет дослідження
Методи, архітектурні патерни та алгоритми комбінаторної оптимізації (CP-SAT), векторного пошуку (pgvector) і сервіс-орієнтованої архітектури (SOA) для забезпечення консистентності даних і масштабованості TravelTech платформи.

## Мета роботи
Проєктування та розробка Cloud-Native платформи сервіс-орієнтованої архітектури для інтелектуального планування подорожей, що поєднує семантичний пошук на базі LLM з детермінованою оптимізацією розкладів задля усунення логістичних хиб генерації.

## Завдання проєкту
1. **Проаналізувати** існуючі аналоги та ринкові рішення в сегменті TravelTech згідно з вимогами ДСТУ.
2. **Обґрунтувати** вибір технологічного стека та архітектурних патернів (FastAPI, PostgreSQL + pgvector, Redis, Celery, Google OR-Tools).
3. **Спроєктувати** архітектуру системи (діаграми C4, схеми реляційної та векторної БД, контракти API).
4. **Розробити** алгоритмічні модулі гібридного рекомендаційного рушія та фонового оптимізатора розкладів (VRPTW).
5. **Налаштувати** інфраструктуру конфігурації, контейнеризацію (Docker Compose) та інтеграцію зовнішніх API (Gemini, Mapbox, Telegram Bot).
6. **Здійснити** інструментальний аудит коду, тестування бізнес-логіки та перевірку надійності під навантаженням.
7. **Провести** науково-практичну апробацію результатів та підготувати супровідну документацію (Docs-as-Code).
